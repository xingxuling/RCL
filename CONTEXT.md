# RCL Current Context

Current package: **RCL Agent Civilization Sandbox v0.82.0-alpha.1**.

This package extends v0.80 Self-Upgrade Team Sandbox and v0.81 Source Map Patch Queue into a compressed hierarchical **Agent Civilization Sandbox（智能体文明沙箱）**. It turns many few-shot agents into a city-like organization: 7 cabinets, 49 departments, 343 role cells, compressed virtual market cohorts, workload packages, evidence court, accelerated future simulation and council verdict.

## Key commands

```bash
node src/cli.mjs agent-civilization-demo
node src/cli.mjs agent-civilization-run examples/agent-civilization/default-agent-civilization.json output/v0.82/agent-civilization-sandbox
node src/cli.mjs agent-civilization-spec output/v0.82/agent-civilization-spec
node --test --test-concurrency=1 tests/agent-civilization-sandbox.test.mjs
```

## Boundary

The v0.82 civilization is a deterministic sandbox organization. It compiles work packages, virtual market feedback, future branches, evidence and release verdicts. It does not mutate the real worktree, push repositories, deploy services, access network or claim complete replacement of the outer model. Human/assistant final authority remains required.

## Current handoff rule

When a future assistant receives this project, it should first consider using the Agent Civilization Sandbox to reduce planning, review, testing, documentation and user-simulation workload before making real source changes.
