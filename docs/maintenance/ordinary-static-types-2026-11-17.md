# Ordinary static type admission

The RCL-authored compiler previously checked expression names and literal facet types but did not apply its existing typed predicate checker to ordinary facet initializers or function bodies. Reproduced native acceptance included `1 + true`, invalid logic/unary operands, incorrectly typed choose/call arguments, mismatched function bodies and incompatible inferred facet results; the reference compiler rejected them.

Ordinary facets and functions now reuse the existing typed expression rules. Each function body is checked once using typed parameters; call sites use declared signatures so recursive and mutually recursive functions do not repeatedly expand their call graphs. Conditional-warrant analysis keeps its previous deeper reachable-body policy. Dynamic `Unknown` values retain the reference policy rather than being treated as statically proved values. The reference checker also now enforces one argument for text, length, number_from_text and text-case/trim utilities; it previously accepted absent/extra arguments.

Fifteen new scoped checks include thirteen malformed type contexts, valid recursive/mutual signatures and dynamic Sequence values, plus twelve utility-arity variants with failed outputs retained. Sixty-one type/warrant/structured-diagnostic checks and seventy-one compiler/lexical/metadata/location checks passed. The 233-example audit still has 195 byte-identical supported examples, 38 reference-unsupported and zero native failures.

Native C0=C1=C2 is `344211328bd6a5cbc000281458eb82eb82eea926f2fed9a426cbea55ee3cc78c` (422,302 bytes). Each generation executes 216,221,150 instructions within the unchanged 300,000,000 instruction budget. The build report now retains both numbers. This is not whole-language type soundness: ordinary rule condition/alteration/preserve typing and other unchecked contexts require separate work. The independent JS RBC suite started for the preceding diagnostic checkpoint remains separately pending; it is not current-source evidence for this increment. No Actions or publication occurred.
