## 使用入口

在该工作树中使用已安装的 Node.js 20 或以上版本：

```powershell
node src/reality-hub-cli.mjs version --json
node src/reality-hub-cli.mjs doctor
node src/cli.mjs native examples/hello-reality.rcl
node src/reality-hub-cli.mjs lsp-rename-preview examples/hello-reality.rcl world.greeting message output/my-rename-preview
node examples/debug-session/replay-cursor-demo.mjs
```

重命名输出目录必须尚不存在。会话创建、调用、备份、历史导出与可信根
校验示例见 [会话契约](../v2.0/session-contract.md)。归档可以作为本地
npm 安装文件使用；最终离线安装过程禁止联网、安装脚本与审计请求。
