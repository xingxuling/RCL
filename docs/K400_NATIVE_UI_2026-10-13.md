## Callable capability

```text
node examples/native-ui/native-event-web-demo.mjs windows
```

Open the printed loopback URL. The same demo accepts `wasm-vm`, `linux` or
`android` when the corresponding actual target is available. The page exposes
increase and reset actions and a Chinese count label. Current state, event
mutations, derived text and render properties come from native RCL execution.
The browser only binds DOM events, transports requests and renders returned
projections. The bridge reuses the existing Native UI DOM/style/accessibility
backend; it replaces that backend's reference semantic script with transport.

Public APIs: `compileNativeUiForExecution`, `lowerNativeUiEvent`,
`createNativeUiEventRuntime`, and `createNativeUiWebBridge`. The generic lowerer
supports typed Number/Text/Truth state, existing UI expressions, derived values,
bindings and local set-state handlers. It preserves simultaneous updates from
the before-state. Unsupported navigation, adaptive extensions, reality-gateway
handlers, duplicate state writes and invalid authority types fail closed.
Negative numeric state literals are normalized at the existing IR boundary.

Every event is lowered to an ordinary RCL program with a conditional mutation
warrant and separate dispatch/paint transactions. The selected target compiles
it using the actual RCL-authored compiler, matches bootstrap bytes, executes it
and produces typed semantic roots. The Node bridge sequences cooperative
in-memory state and revisions between these native executions. This is not a
claim of durable UI state or an entirely self-hosted UI process.
