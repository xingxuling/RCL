# 万风对话流态模型 v0.1

> 代码标识：`WanFengDialogueFlow`（万风对话流态）
>
> 定位：面向主体保真、角色模拟、同人写作、社交仿真与智能体交互的**交流动力学层**。它不负责决定“一个人相信什么”，而负责决定“这个人在此刻如何把内部状态流成现实中的语言、停顿、连续输出、修正与协议切换”。

## 1. 为什么需要这一层

传统对话模型很容易默认：

`A 说一句 → B 说一句 → A 再说一句`。

这会把真实交流错误压缩成固定轮替。万风模型把对话视为动态流场：一个主体可以根据对象、关系、兴趣、分寸、认知负荷和现场反馈，在轮替、连续输出、压缩跳跃、即时修正、观察、转向等流态之间切换。

“像风”不是文学标签，而是一个控制原则：**没有固定的单一输出节奏；状态随对象与情境改变，同时保留稳定的主体边界。**

## 2. 通用状态空间

### 2.1 流态

- `adaptive`：自适应，默认状态。
- `turn_exchange`：轮替交流，频繁让出话轮。
- `burst_chain`：连续句群，一句接一句，直到当前语义簇完成后再让出话轮。
- `compressed_jump`：压缩跳跃，允许省略主体已经内部完成的中间步骤。
- `self_repair`：即时修正，允许边说边改、撤回、补充或重定向。

这些状态不是人格标签，而是可切换的瞬时交流模式。

### 2.2 对象协议

- `very_young → sensory_playful`：极低龄对象，优先感官、互动和游戏性。
- `child → concrete_playful`：儿童对象，优先具体、可玩、低抽象度表达。
- `peer → peer_contextual`：同龄/同层对象，根据关系和话题动态调节。
- `elder → experience_contextual`：年长对象，优先经验、生活情境与关系接口。
- `expert → high_density`：专业对象，在确认对方可承载时允许高密度交流。

协议切换的核心不是“装成不同的人”，而是**保持同一主体，改变接口带宽和表达形式**。

## 4. 必须保留的关键规律

### 4.1 对话不是固定轮替

同一主体可以：

`短答 → 顺着聊 → 连续输出 → 突然停 → 看反馈 → 换方向 → 再进入轮替`。

因此，生成器不得用固定 ABAB 节拍模拟主体。

### 4.2 连续输出不等于演讲

`burst_chain`（连续句群）应允许短句、半句、补充、实时修改、突然插入例子和回拉主线。禁止自动把它润色成结构完整的演讲稿或 AI 风格长段落。

### 4.3 对方沉默不自动等于震撼

当前 RCL 资产显式写入：

`listener_signal == silence → processing_or_reflection`

即沉默首先保留为“可能在处理/思考/反省”的开放解释，并禁止直接推断为敬畏、被压制、被说服或识破主体能力。

### 4.4 内部推理与表面语言分离

主体内部可能完成：

`A → B → C → D`

实际输出却可能只有：

`A → D`

甚至只说 D。主体保真系统不得为了让读者看懂，就强制把 B、C 全部变成角色台词。

### 4.5 他人识别主体需要时间

其他角色不应在初次交流几分钟内自动获得“这个人很强/思维很快/很特殊”的准确元判断。识别本身应拥有延迟、误判和逐渐校准过程。

## 5. 反模式清单

以下行为会直接降低杜衡界主体保真：

1. 固定 `你一句—我一句`。
2. 把连续输出写成排版漂亮、逻辑桥完整的长篇演讲。
3. 把他人的沉默自动戏剧化成震撼或压迫感。
4. 把内部分析日志全部变成说出口的话。
5. 对儿童、同龄人、老人、专业人士使用同一套语言协议。
6. 让所有角色过快识别主体能力与真实意图。
7. 只让主体与主角、天才、强者产生自然互动。
8. 把“像风”简化成“说话快”或“话很多”。
9. 把任何一次流态冻结成稳定人格标签。

## 6. RNCS / 角色模拟接入契约

建议把本模型放在“主体内部状态”与“表面语言生成”之间：

```text
主体模型 / DSM / 注意力 / 情绪 / 当前目标
                ↓
          场景与对象状态
                ↓
     万风对话流态模型（WFDF）
       ↓          ↓          ↓
    流态选择    话轮控制    对象协议
       ↓          ↓          ↓
       表面语言 / 停顿 / 动作 / 连续输出
                ↓
          对方真实反馈
                ↓
       延迟、误解、关系状态回流
```

其中 `WFDF` 是 `WanFeng Dialogue Flow` 的代码简称，中文即“万风对话流态”。它只管理**表达动力学**，不取代 DSM（主体模型）、情绪模型、注意力模型或世界状态。

### 最小输入

- 对象年龄/认知接口
- 熟悉度与关系
- 当前话题兴趣/动量
- 社交边界与场合
- 对方已表现出的处理负荷
- 当前情绪与精力
- 是否需要快速完成当前语义簇

### 最小输出

- 当前流态
- 是否继续占有话轮
- 预计连续输出长度区间
- 推理显式程度
- 是否允许即时自修正
- 对象协议
- 对方沉默的非确定性解释

## 7. 与“万风”概念的关系

这里的“万风”不是把现有剑道/哲学设定机械搬进聊天，而是提取同一个更底层结构：

**变化而不失主体、适配而不固定、连续而可收束、转向而不必重启。**

所以它可以作为万风体系在“交流与社交动力学”上的正式派生资产。

## 9. 后续升级方向

v0.1 先把核心结构固定下来。下一阶段最有价值的是从真实聊天/小说样本中学习**状态转移概率和对象特异参数**，而不是继续手填更多人格形容词。届时可加入：

- 每个对象独立的处理延迟估计；
- 连续句群长度分布；
- 话题转向与回拉概率；
- 语义压缩率；
- 被打断后的恢复模式；
- 熟悉度变化后的协议漂移；
- 真人对话与同人对白之间的差异回归测试。

最终目标不是生成“像杜衡界写的句子”，而是让模拟主体在互动过程中**以接近杜衡界本人的方式流动**。
