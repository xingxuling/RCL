# RCL Frontier Unknown-Law Experiment Specification v0.1

**状态**：`PASS / Phase2A experiment specification compiler established / real unknown-law acquisition not started`  
**日期**：2026-08-11  
**基线**：RCL v0.94.0-alpha.1 + Frontier Phase0–1F

## 0. 目标裁决

Phase0–1F 已经建立：候选机制、数学化、沙箱、盲测、外部数据合同、独立进程边界、公开科学数据回验、Design Grammar、Scorer Router 与机器可验证预注册。

Phase2A 不再继续扩实验室，而是第一次把具体未知自然规律候选编译成**现实实验规格**：

```text
Candidate mechanism root
→ measurable variable
→ design grammar
→ instrument contract
→ null + ordinary alternatives
→ independent acquisition protocol
→ stop conditions
→ promotion gates
```

这一版选三条首发研究线：

1. `spell_symbolic_control_protocol`
2. `formation_spatial_constraint_array`
3. `aether_substrate_information_medium`

## 1. 当前裁决

### A. Symbolic Control × Spatial Context

- Design Grammar：`simple_2x2`
- 当前分析运行时：`READY_EXISTING_SIMPLE_2X2_SCORER`
- Primary response：`primary_sensor_residual`
- 目标项：`symbol_program × spatial_context`
- 采集边界：独立进程/设备先生成并封存原始文件，RCL 后读取
- 核心 Null：在 syntax-matched null、随机/旋转空间控制、环境漂移和普通通道解释后，interaction = 0

这是当前**第一条可以继续进入现实 acquisition 设计**的未知规律规格。

### B. Formation Spatial Constraint Array

- Design Grammar：`full_factorial_2powk`
- Factors：`layout_topology × orientation × boundary_mask`
- Expected cells：8
- 当前状态：`BLOCKED_PENDING_GENERIC_FULL_FACTORIAL_PAYLOAD_ADAPTER`

阻断原因不是候选失败，而是 Phase1E 当前 full-factorial scorer 的 payload adapter 仍绑定公共 NIST fixture 结构；未知实验不能假装复用一个不合法的数据入口。

### C. Aether Substrate Information Medium

- Design Grammar：`continuous_field`
- Primary response：`cross_channel_residual_correlation`
- 目标：distance / phase / shield 条件下的 holdout transfer kernel
- 当前状态：`BLOCKED_PENDING_CONTINUOUS_FIELD_SCORER`

Phase1E 已明确规定 continuous-field 没有专用 scorer 时必须 BLOCKED。因此 v0.1 只冻结实验问题、仪器/时钟要求、普通泄漏模型、独立设备采集协议与停止条件，不提前采集可被事后分析污染的数据。

## 2. Promotion Gate

三条研究线都不能因为“出现异常”直接升级。最少必须满足：

```text
预注册 design/null/analysis
+ 独立 acquisition
+ raw root / provenance / calibration
+ known positive control 同管线通过
+ null/negative controls 全保留
+ ordinary competing models 未能解释决定性残差
+ 至少两次独立 acquisition 重现方向
+ 强自然规律声明前需要第三方或真正独立设备复现
```

## 3. 多文明联邦审查

- **Founder Twin**：研究问题从“能不能放魔法”重命名为“哪个可测残差能在普通模型之后仍然存活”。
- **柳清莲 Gate**：所有 spell / formation / aether 仍是候选标签，不可作为真实存在前提。
- **洞哥 Grounding**：每条规格必须有 primary variable、仪器要求、Null、普通替代模型、停止条件和 acquisition boundary。
- **产品文明**：用户界面最终只需要显示 `READY / BLOCKED / next gate`，不展示神秘化成功按钮。
- **UX / 设计文明**：primary 与 exploratory channels 分离；secondary channels 不能事后升级主假说。
- **工程文明**：直接绑定 Frontier Natural Law Lab candidate root，不另造候选体系。
- **代码文明**：Spec 本身 root-bound；seal 后改 Null 会造成 root mismatch。
- **测试文明**：三条 candidate root 必须存在；spell 可进入现有 2×2；formation/aether 必须 fail-closed 在当前缺口。
- **安全文明**：v0.1 禁止人体实验和破坏性物理实验；只定义低风险仪器/数据合同。
- **发布文明**：源码、测试、demo、spec 文档和 Evidence Ledger 同步交付。
- **Integration Court**：只有 `externalRealityVerified=false`、`magicVerified=false` 保持时 Phase2A 才可 PASS。
