## Contradictions resolved

1. The uploaded claim that IAL already has multi-sort, effect-type and complete governance-obligation formalization was not matched by the audited Markdown or executable adapter. Those properties remain `UNKNOWN`, not accepted facts.
2. SNLL's own documents label automated gates VERIFIED, but the audited implementation is uncommitted in the current worktree. Federation status therefore remains local candidate.
3. CSL is more than a proposal, but a clean `npm ci` fails because `package.json` and `package-lock.json` are out of sync. Executability and release reproducibility are separate.
4. RSL was a product-surface intention, not an implementation. This repository now introduces only a frozen create-project candidate subset.
5. ASIL may own Meaning Graph inside UPDIA without owning RCL reality semantics or authority. The scopes are non-overlapping.
