# Auxiliary Language Definition v0.1

An **Auxiliary Language** is a versioned language organ that is locally optimal for a subject, culture, domain or execution environment. It preserves declared meaning, authority and evidence through a registered semantic contract, while explicitly declining ownership of TaoWind's global reality semantics unless separately promoted.

It is not a reduced RCL and it does not gain authority by syntax. Its organ completeness is evaluated as:

- Skeleton: identity, grammar/schema and version;
- Muscle: parser/compiler/translator;
- Blood: meaning, state and evidence flow;
- Nerve: diagnostics, validation, negative and round-trip tests;
- Organ: stable interface and explicit ownership boundary.

An auxiliary language can remain valuable indefinitely. Promotion to canonical RCL genome is considered only when the semantic capability is cross-domain, intrinsic to reality compilation and cannot remain cleanly profile- or adapter-owned.
