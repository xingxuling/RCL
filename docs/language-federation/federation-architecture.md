# Federation Architecture and Integration Court v0.1

## Frozen candidate architecture

```text
Living / regional / domain surfaces
  -> one registered semantic profile
  -> ASIL Meaning Graph candidate
  -> RCL candidate/reality semantics
  -> specialized execution adapters
```

This is a shared contract/registry/test layer, not a new OS and not a second canonical core. Language implementations stay in their own repositories.

## Profile rule

The interlingua is not an unbounded mega-schema. Each source declares only the applicable profile. v0.1 freezes General Meaning, Programming, Governance, Social/Living, Structural Domain and Canonical Reality profiles. Unsupported fields remain unknown or block translation.

## K400 integration

Universal Stress now has five donor outcomes:

```text
REJECT
ORGAN_ONLY
AUXILIARY_LANGUAGE
EXPERIMENTAL_GENOME
CANONICAL_RCL_GENOME
```

`AUXILIARY_LANGUAGE` requires passed stress evidence, sufficient evidence, preserved RCL identity, no opaque delegation credit and no canonical-semantic claim. It is not a shortcut around genome promotion.
