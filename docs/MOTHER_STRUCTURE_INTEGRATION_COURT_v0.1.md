# Mother Structure Integration Court v0.1

This is the second, candidate-only stage after the K400/native-ui/package/Forge
archaeology and DWAC clustering pass. It checks whether a repeated structure is
safe to retain as a Framework/std/Pack/Example/Auxiliary recommendation without
turning that recommendation into a compiler or registry mutation.

## Inputs

- `rcl.mother-structure.corpus.v0.1` and its verified root;
- optional `rcl.universal-stress.evidence.v0.1`;
- the four current RCL-owned target candidates:
  `rcl.rule.authorized_transition`, `rcl.facet.declaration`,
  `rcl.authority.subject_warrant`, and `rcl.rule.foresee_realize`.

The Court reuses the existing K400 matrix and nine non-compensatory gates. It
does not create a second K400 definition, score gate, or promotion path.

## Local controls

Each target receives:

1. a positive parser/Mother-IR fixture;
2. a negative fixture with the required semantic material removed;
3. a structural mutation check that must observe a changed or absent target;
4. an identifier-rename invariance check over `shapeRoot`;
5. the corpus recurrence, independent-source, and cross-scope threshold check;
6. candidate-only, no-registry-write, no-authority-transfer, and no-formal-gap
   boundary checks.

The local result is `PASS_LOCAL` only. It is not compiler execution, native VM
execution, provider execution, device execution, package release proof, or
formal `RCL_GAP` proof.

## Decision vocabulary

`RETAIN_AS_FRAMEWORK_CANDIDATE` and `RETAIN_AS_STD_CANDIDATE` mean retain the
classification for further evidence. `RETAIN_AS_PACK`, `RETAIN_AS_EXAMPLE`,
and `RETAIN_AS_AUXILIARY_LANGUAGE_PROVIDER` preserve the bounded ownership
decision. `HOLD_AS_RCL_GAP_CANDIDATE` never asserts a formal gap. Every result
has `promotion: NOT_AUTOMATIC`.

The overall verdict is `CANDIDATE_ONLY_HOLD` when local controls pass. A
complete K400 matrix is not inferred from the Court: the current 23 claimed
cells and 377 untested cells remain `INCOMPLETE`.
