`createPortableGameTarget()` compiles an arbitrary supported RCL hook with the
native RCL-authored compiler. Every fixed step actually starts the native C VM,
verifies the hook's typed state root and exact source identity, and transports
the output into the source-owned `game-frame.rcl` controller. Each child receipt
records its real process id, exit status, monotonic samples and output hashes.

The host's explicit procedural binding maps finite Numbers modulo 17, Truth to
0/1, and Text lengths modulo 17, recursively summing sequences/state in stable
order. It is a bounded transport projection. RCL determines the velocity from
that signal and actual input, integrates position/gravity, clips horizontal and
ground collisions, updates score and frame count, and checks conditional scene
authority. The binding grants no domain understanding or authority to Node.

The reused renderer projects verified native scene state into rectangles/SVG;
it does not advance physics or change canonical state. The local API is a
deterministic fixed-step game runtime. Browser execution, physical frame timing,
commercial engine parity and external effects are outside this profile.
